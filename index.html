How I build

Trustworthy by construction

Four rules I apply wherever an AI output can move money, approve a claim or end up on a signed drawing.

Code decides. The model explains.

Prices, layouts, approvals and money movement come from deterministic code. LLMs read, extract and explain, and every output is schema-validated before code acts on it.

Forward pricing →Rivvet →

Every number is traceable.

Grounding checks reject answers whose figures don't trace to evidence, and RAG answers cite the page or decline to answer.

Grounding checker →Cited RAG →

Humans hold the keys.

Agents prepare; named people approve. Send credentials, payments and final decisions stay behind gates a model can't open.

Procurement agent →Approval gates →

Boring, reliable infrastructure.

Lean AWS deployments with Docker, systemd, HTTPS, idempotent jobs, restore-tested backups and health-gated rollbacks.

Leased job queue →Tested restores →
