# karun-ch.github.io

Personal portfolio of **Karunakar Cheekolu**, AI Engineer, live at **https://karun-ch.github.io**.

Six case studies of production AI systems (LLM agents, RAG, grounded assistants and the AWS infrastructure under them), each with an architecture diagram, key engineering decisions and measured results.

## How it's built

- Plain HTML, CSS and a small amount of progressive-enhancement JavaScript. No framework, no build step on GitHub Pages.
- Pages and the theme-aware SVG architecture diagrams are generated by a small Python script (standard library only) from a JSON content file.
- Light and dark themes, a `Ctrl/⌘ K` command menu, reduced-motion support, and pages that work fully without JavaScript.
- SEO: canonical URLs, Open Graph/Twitter cards, JSON-LD (`ProfilePage`, `Person`, `TechArticle`), `sitemap.xml`, `robots.txt`.

## Structure

```
index.html              homepage
work/<slug>/index.html  case studies
404.html                not-found page (served automatically by GitHub Pages)
assets/css/style.css    design system (tokens, components, diagram styles)
assets/js/main.js       theme toggle, menu, scroll reveal, command menu
assets/og.png           social share image
```
